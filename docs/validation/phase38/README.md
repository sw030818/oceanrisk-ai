## UI·보안·한계

현재 미확인 근거/최초 AI 진단/복구를 분리한다. 확정 오류0이라도 현재 근거가 미확인이면 검토 미완료다. 원인ID/영향필드/연관비교/원본검사를 보존하고 대표 행을 기본 표시한다. 전체 필터·근거 모달·수정/복원·PDF 원문을 유지하며 모바일 카드/데스크톱 표와 간결한 인쇄 부록을 제공한다.

기존37 예산115문서/115요청/$0.10917903은 보존하며 재사용하지 않는다. PHASE38 새 유료 호출은 별도 승인 전0회다. 제안한8문서/8요청/최대$0.10/자동재시도0 전용 러너는 기존37과 별도 ledger를 사용하고 요청 전 상한을 예약한다. 미확인 사용량은 비용을 유지한다. 플래그나 러너의 존재는 사용자 승인을 대신하지 않는다. 원본3개와 실제 스트림 변형5개를 대상으로 하며, 변형은 개별 합성 오류이고 독립 새 양식으로 세지 않는다. 비용·문서·요청 중 하나라도 한도에 도달하면 중단한다.

기존 수출자/Shipper·구매자/Consignee 역할은 일괄 동일시하지 않는다. 지원하지 않는 번역/추가 규격·복수 신고 배분·OCR·누락 참조는 필요한 보류를 유지한다. 업무 PDF 일반화나 신고 적법성·과태료 예방을 보장하지 않는다.
