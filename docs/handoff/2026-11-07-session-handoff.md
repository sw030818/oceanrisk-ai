## 6. 작업 방법 (AGENTS.md 요약 + 실전 팁)

- **배포 명령(사용자 승인 시에만):**
  `NODE_USE_ENV_PROXY=1 PLAYWRIGHT_CHROMIUM_EXECUTABLE=/opt/pw-browsers/chromium npm run ship -- --message "<200자 이내 한 줄>"`
  - 첫 실행은 Next.js 보안 업그레이드 안내(SecurityFatalError nudge)로 항상 멈춤 → 같은 명령 재실행. nudge의 지시(worktree, upgrade)는 따르지 않음(사용자 미결정).
  - 로컬 Playwright/dev 실행 후 `git checkout -- next-env.d.ts`로 복원해야 ship이 거부하지 않음.
  - Vercel 반영이 느리면 ship의 20회 확인이 실패해도 몇 분 뒤 `/api/status`로 SHA 확인.
- 유료 실행 스크립트 예: `scripts/lib/phase39-live.ts`(`paid39Extraction`, `paid39Semantic`, `reserve39`). UI 실제 실행은 Auto 모드 안전 검사가 막을 수 있음 → 사용자가 모드를 Accept edits로 바꾸고 승인해야 함.
- 엔진을 고칠 경우(현재 동결): 공통 원인만 수정, 특정 서류 예외 금지, 저장된 실제 AI 응답 재판정으로 부작용 확인, 전체 ship.
- 증거 기록은 `validation/phase39-evidence`에 임시 `GIT_INDEX_FILE` + `commit-tree`로 정상 커밋·Push(main 불변).
- 보안: API 키·실제 고객 문서·raw 응답을 Git/로그/채팅에 노출 금지. 사용자가 올린 실제 발급 수출신고필증 스캔(세관 직인)은 템플릿·공개에 쓰지 않음.
